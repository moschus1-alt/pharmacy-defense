# 약국 디펜스

한국 동네 약국을 배경으로 한 5레인 캐주얼 타워디펜스 프로토타입입니다.

## 실행

```bash
npm install
npm run dev
```

## 현재 구현 (Phase 1–2)
- Phaser 3 + TypeScript + Vite
- 모바일 가로형 1280×720 기준 FIT 스케일링
- 5×9 터치 그리드
- 5개 독립 레인
- 적 랜덤 스폰 및 왼쪽 이동
- 빈 셀 터치로 기본 공격약 배치
- 매출 자원 소비/자동 생성
- 같은 레인 타겟 탐색
- 자동 투사체 공격
- 충돌, HP, 피격 피드백, 사망

현재 그래픽은 placeholder입니다. 실제 스프라이트는 투명 PNG, 동일 canvas, bottom-center pivot 규칙으로 교체합니다.

## 다음 단계
자원 유닛/탱커/감속 등 유닛 확장, 적-방어유닛 접촉 전투, 웨이브/스테이지, 애니메이션 상태 머신, 모바일 UI를 추가합니다.
